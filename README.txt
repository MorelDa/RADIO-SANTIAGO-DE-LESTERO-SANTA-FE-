RADIO PARTY VALENCIA - PWA

Archivos:
- index.html
- manifest.webmanifest
- service-worker.js

Sube los tres archivos a la raíz del repositorio de GitHub Pages.

IMPORTANTE:
1. GitHub Pages debe servir el sitio por HTTPS.
2. El botón "Instalar App" aparece automáticamente cuando el navegador considera instalable la PWA.
3. El botón Compartir usa Web Share API cuando está disponible.
4. Los metadatos Open Graph usan:
   https://i.ibb.co/LhDPnt7b/N.png
5. Para cambiar la imagen de compartir, cambia og:image y twitter:image.
6. El favicon también usa el mismo logo.

NOTA:
La vista previa de WhatsApp/Facebook/Telegram puede tardar en actualizarse porque esas plataformas guardan caché de las metas. La URL pública debe ser rastreable y la imagen debe estar accesible por HTTPS.
